# Scroll Market — Landing Page & Cotizador Interactivo

Landing Page de alta conversión diseñada y desarrollada para la venta del software de punto de venta y gestión de comercios **Scroll Market**, junto con toda su línea de equipamiento de hardware (impresoras térmicas, lectores de códigos de barra, y computadoras completas).

---

## 🚀 Características y Secciones Incluidas

1. **Header & Navegación:**
   - Barra superior con aviso de promociones y botón directo al cotizador.
   - Logo de marca con isotipo moderno y menú responsive (Desktop y Mobile).
   - Acceso rápido a demostración y selector de planes.

2. **Hero Section (Impacto & Conversión):**
   - Propuesta de valor clara para comercios (Minimarkets, Kioscos, Ferreterías, Petshops, Bazares, etc.).
   - Maqueta interactiva visual simulando la interfaz de venta del POS en tiempo real con escaneo de código de barras.
   - Badges de confianza: Plug & Play, tickets en < 1s, sin contratos forzosos.

3. **Segmentos de Negocio:**
   - Iconografía y llamados dirigidos a distintos rubros comerciales.

4. **Beneficios Principales del Software:**
   - Punto de venta ágil, control de stock en tiempo real, turnos de caja ciega, facturación fiscal / no fiscal, estadísticas y compatibilidad de hardware.

5. **Nuestros 4 Planes y Combos Principales (Requerimiento Clave):**
   - **Plan 1: Software Solo (Licencia Digital):** Para comerciantes que ya tienen su computadora, ticketera y lector.
   - **Combo 2: Software + Impresora Térmica + Lector de Mano USB:** El kit esencial más vendido.
   - **Combo 3: Software + Impresora + Lectores Especializados:** Detallando la opción de **Lector de Mesa Omnidireccional 2D**, **Lector Móvil / Inalámbrico** o el combo con **Los Dos Lectores**.
   - **Combo 4: Llave en Mano Completo con Computadora:** Incluye Computadora / All-In-One con SSD + Monitor + Impresora + Lector + Gaveta de dinero metálica + Software preinstalado.

6. **Cotizador Interactivo ("Arma tu Combo a Medida"):**
   - El cliente selecciona paso a paso su software, modelo de impresora térmica, tipo de lector de barras, computadora y accesorios opcionales (gaveta, balanza).
   - El resumen del combo se actualiza en tiempo real en pantalla.
   - Botón directo de **WhatsApp** que genera automáticamente un mensaje ordenado y detallado con la configuración elegida para cerrar la venta inmediatamente.

7. **Comparativa Técnica de Lectores de Código de Barras:**
   - Explicación didáctica sobre cuándo conviene el lector de mesa, cuándo el móvil inalámbrico y cuándo conviene tener ambos.

8. **Proceso de Implementación en 4 Pasos:**
   - Elección, entrega/instalación, carga de artículos y puesta en marcha.

9. **Preguntas Frecuentes (FAQ):**
   - Respuestas a objeciones comunes (compatibilidad, funcionamiento sin internet, soporte técnico).

10. **Llamado a la Acción Final & Botón Flotante de WhatsApp:**
    - Botón flotante accesible en todo momento para atención instantánea.

## 🛠️ Personalización Rápida

### Cambiar el número de WhatsApp:
Abre el archivo [app.js](file:///c:/Users/PC/OneDrive/Imágenes/ANDREA/landing%20market/app.js#L7-L12) y modifica la línea:
```javascript
const CONFIG = {
  whatsappNumber: "5491100000000", // Reemplaza con tu código de país y número sin '+' ni espacios
  defaultCurrencySymbol: "$",
};
```

### Precios o Moneda:
Puedes colocar precios numéricos específicos directamente en las tarjetas de [index.html](file:///c:/Users/PC/OneDrive/Imágenes/ANDREA/landing%20market/index.html#L260-L380) según la moneda de tu país (ej. ARS, USD, MXN, COP, etc.).
